Research

I'm broadly interested in robot learning. The goal of my research is to build agents that can make intelligent decisions in embodied environments and have generalizable motor skills in challenging scenarios, like TARS and CASE from my favorite movie Interstellar. Recently, I am interested in leveraging internet-scale data to improve generalization of robot capabilities.

Code as Policies: Language Model Programs for Embodied Control
Jacky Liang, Wenlong Huang, Fei Xia, Peng Xu, Karol Hausman, Brian Ichter, Pete Florence, Andy Zeng
arXiv, 2022
project page / paper / explainer video

Using hierarchical code generation, large language models can write robot policy code that exhibits spatial-geometric reasoning when given abstract natural language instructions, without any additional training.
Inner Monologue:
Embodied Reasoning through Planning with Language Models

The Conference on Robot Learning (CoRL), 2022
project page / paper / explainer video
